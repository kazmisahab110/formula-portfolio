# 🏎️ Formula Racing Portfolio

### An Interactive 3D Developer Portfolio

A Formula racing-inspired portfolio that transforms the traditional developer website into an interactive driving experience.

Visitors can drive a Formula-style race car around a custom 3D circuit, discover projects through interactive checkpoints, explore technical skills, and learn about my software development experience.

**[🚀 Live Demo](https://formula-portfolio.vercel.app/)** | **[💻 GitHub Repository](https://github.com/kazmisahab110/formula-portfolio)**

---

## Overview

Formula Racing Portfolio combines interactive 3D graphics, game mechanics, and modern frontend development to create an engaging way to showcase software engineering projects.

The application offers two ways to explore:

- **Interactive Racing Mode:** Drive around a 3D circuit and interact with portfolio checkpoints.
- **Direct Navigation:** Access About, Projects, Skills, and Contact sections through the navigation bar.

## Key Features

### Interactive 3D Racing

- Custom Formula-style racing car and circuit
- Keyboard-based acceleration, braking, reversing, and steering
- Camera-follow system with smooth movement
- Track boundaries, barriers, and collision handling
- Grass friction and vehicle movement physics

### Racing Experience

- Five-light starting countdown
- Speed and gear display
- Race timer and lap tracking
- Three-lap race challenge
- Race completion screen and replay functionality

### Interactive Portfolio

- Trackside checkpoints for About, Projects, Skills, and Contact
- Keyboard-based checkpoint interaction
- Project cards with technology badges and repository links
- Direct navigation for visitors who prefer not to race
- Responsive interface for different screen sizes

### 3D Environment

- Procedurally generated racing circuit
- Curbs, runoff areas, and safety barriers
- Trackside trees and lighting structures
- Pit building, grandstand, and sponsor signs
- Start/finish line and track decorations

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/kazmisahab110/formula-portfolio.git
cd formula-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local address shown in your terminal, typically `http://localhost:5173/`.

### Production Build

```bash
npm run build
npm run preview
```

## Controls

| Key | Action |
|---|---|
